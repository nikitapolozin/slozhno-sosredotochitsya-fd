# Сложно сосредоточиться

Учебный проект курса «Фронтенд-разработчик» от Яндекс.Практикума  
(спринт 3, блок «Адаптивность и графика»).

**[Демо-страница](https://nikitapolozin.github.io/slozhno-sosredotochitsya-fd/)**

## Описание

Адаптивная вёрстка лонгрида о том, почему нам так сложно сконцентрироваться и что с этим делать. Страница включает полноэкранную шапку с переключателем цветовых тем и крупным логотипом, три текстовых раздела («Почему сосредоточиться так сложно», «Что снижает концентрацию внимания», «Как концентрироваться лучше»), галерею иллюстраций и полноэкранный подвал.

У страницы три режима оформления: светлый «день», тёмный «неон» и «авто», который подстраивается под системную тему пользователя. Вёрстка рассчитана на ширину от 375 до 1440 пикселей, макеты даны для 375, 768 и 1024 пикселей.

Проект начинался с **частичной заготовки**: скрипт переключения тем, сброс стилей, шрифты, изображения и пустые файлы стилей с подсказками. В разметке было только меню тем. Разметку контента, все стили, переменные и обе цветовые темы нужно было сделать самостоятельно.

## Что было сделано

- Собрана семантическая HTML-структура: `header`, `main` с четырьмя секциями (`why`, `causes`, `advices`, `gallery`), `footer`
- Вёрстка построена по принципу mobile-first с точками перелома 768 и 1024 пикселя: разделы перестраиваются из одной колонки в сетку `1fr 2fr`, а затем в три равные колонки
- Шапка сделана на всю высоту экрана (`100dvh` с минимальной высотой) на CSS Grid (`grid-template-rows: 1fr min-content 1fr`). Размер логотипа плавно меняется через `clamp()`
- Фоновое изображение страницы зафиксировано относительно окна (`background-attachment: fixed`): при прокрутке оно стоит на месте, а контент едет поверх него. Картинка своя для каждой цветовой темы и подставляется через CSS-переменную
- Декоративные уголки в шапке и подвале и индикатор REC с подсвеченной точкой сделаны на псевдоэлементах `::before` и `::after`. REC показывается только в неоновой теме
- Цветовые темы построены на CSS-переменных. Режим «авто» работает через медиазапрос `prefers-color-scheme`. Ручной выбор темы задаётся классом на `:root`, и его селектор специфичнее медиазапроса, поэтому он перекрывает системную тему
- Галерея свёрстана на CSS Grid с явной расстановкой ячеек разного размера. Изображения заполняют ячейки через `object-fit: cover`
- Шрифт IBM Plex Mono подключён локально через `@font-face` с `font-display: swap`
- Для отступов и размеров использованы логические свойства (`inline-size`, `block-size`, `inset-*`, `margin-block-end`)
- Учтены состояния интерактивных элементов: `hover` и `focus-visible` у кнопок тем и ссылок
- Вёрстка сверена с макетами на трёх ширинах в светлой и тёмной теме (подход Pixel Perfect)

## Технологии

- HTML5 (семантическая разметка)
- CSS3: Grid Layout, Flexbox, CSS-переменные, медиазапросы (в том числе `prefers-color-scheme`), `clamp()`, логические свойства, псевдоэлементы
- JavaScript: готовый скрипт переключения тем с сохранением выбора в `localStorage`
- Методология БЭМ для именования классов
- Плагин Pixel Perfect для сверки вёрстки с макетом
- GitHub Actions: автотесты Практикума

## Чему научился

- Подход mobile-first: базовые стили для мобильных, усложнение сетки через медиазапросы `min-width`
- Сложные сетки на CSS Grid: разная структура колонок на разных ширинах и галерея с ячейками, занимающими несколько строк и колонок
- Цветовые темы на CSS-переменных: автоматическая тема по системным настройкам и ручное переключение, которое её перекрывает
- Специфичность селекторов на практике. Например, `:not()` получает вес своего аргумента и может незаметно перебить правило, которое кажется более точным
- Точная сверка вёрстки с макетами на нескольких ширинах с помощью инструментов разработчика и Pixel Perfect. Мелкие расхождения часто дают строчные изображения и округление межстрочного интервала

## Как запустить локально

```bash
git clone git@github.com:nikitapolozin/slozhno-sosredotochitsya-fd.git
cd slozhno-sosredotochitsya-fd
```

Открыть файл `index.html` в браузере (либо через расширение Live Server в редакторе кода).
